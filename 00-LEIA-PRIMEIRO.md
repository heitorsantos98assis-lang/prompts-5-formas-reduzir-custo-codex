# 00 — Leia primeiro

Esses 5 prompts sao um corte cirurgico em 5 categorias de ferramenta SaaS que custam caro e que o Claude Code (ou Claude.ai) substitui sem perda de qualidade na maioria dos casos de pequenas e medias empresas.

## A logica

Voce nao paga ferramenta SaaS pelo software em si. Voce paga pelo **valor que ela entrega**. Quando o Claude entrega o mesmo valor, a ferramenta vira custo puro.

## Onde isso funciona muito bem

- Empresa com ate ~30 pessoas
- Volume baixo a medio (centenas, nao milhoes, de operacoes/mes)
- Ja tem alguem na equipe minimamente confortavel com o Claude

## Onde NAO funciona

- Operacao com SLA de milissegundos (chat de suporte alto volume)
- Compliance que exige fornecedor certificado (SOC 2, HIPAA, LGPD enterprise)
- Tarefa que precisa rodar 24/7 sem ninguem rodar

Para tudo isso, ferramenta SaaS continua melhor.

## Como rodar os prompts

Voce pode usar de tres formas:

1. **Claude.ai (web)** — abre, cola, usa. Mais rapido para tarefa pontual.
2. **Claude Code (CLI)** — instala uma vez, usa via terminal. Vale para quem vai rodar varias vezes ou automatizar.
3. **API** — para integrar dentro de um sistema seu. Sai pela API com cobranca por token.

Cada prompt tem dica de qual modo e melhor.

## Ordem sugerida

Nao precisa rodar em ordem, mas se quiser priorizar pelo retorno:

1. **02 — AUTOMACAO** (Make/Zapier custam caro e Claude resolve grande parte)
2. **03 — ANALISE DE DADOS** (BI sai caro, dashboard textual resolve 80%)
3. **01 — COPYWRITING** (alta frequencia de uso = alta economia)
4. **04 — ATENDIMENTO** (depende do volume — mede antes)
5. **05 — DOCUMENTOS** (ganho menor, mas ja paga ferramenta sozinho)

## Aviso

Antes de cancelar qualquer ferramenta, rode em paralelo por 1 semana. Migrar mal sai mais caro do que pagar a mensalidade.
